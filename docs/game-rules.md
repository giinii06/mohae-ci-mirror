# MOHAE v1 rules and acceptance criteria

| Mechanism | Rule |
|---|---|
| Attendance | 40 MOHAE + 20 XP, once per KST game day |
| Daily self-reflection quest | 60 MOHAE + 40 XP + 80 season XP, optional text not stored by default |
| Minigame | Four rewarded finished sessions/day, 10 MOHAE + 10 XP each (win and loss equal); no reward on abandonment |
| Chat | Five permitted messages separated by at least 60 seconds yield 5 MOHAE |
| Voice | At least two real humans, eligible channel non-AFK; 20 counted minutes yield 10 MOHAE |
| Shared activity | 10 MOHAE/day across chat and voice |
| Weekly | Complete 3/5 tasks to claim 300 MOHAE + 200 permanent XP + 300 season XP, previous-week 7-day grace |
| Gacha | Single 150; ten 1,500; tickets count as draws and advance pity |
| Pity | 2+ after max 10; 3-star by max 60; limited pickup by max 70; 50:50 loss guarantee |
| Characters | person1-12 one star; person13-20 two; person21-24 standard three; person25 Joker three; person26 limited three; person27 season reward |
| Dismantle | 1/5/40 shards by rarity; protected last copy; optional duplicate 1/2 auto only |
| Affinity | 10 first representative-character talk/day and 10 first gift/day; no stories |
| Season | Manually scheduled Monday 05:00 KST, 56 days, 20 tiers at 250 season XP/tier |
| Pass rewards | Ten free draw tickets, 100 shards, dummy cosmetics and person27 |
| Events | Three operator-enabled dummy events at 200 MOHAE each (600 total) |
| Coop | Operator-set goal, max three contribution units/user/day, all participating users earn same dummy badge |
| Profile | Private by default, opt-in public display; personal data download and journal deletion |
| Reporting | Polly-only sensitive reports, staff triage, no reward; protected staff channel |
| Nickname color | Optional 12 manually configured Discord roles, only one active game palette role |
| Non-goals | Stories, choices, dialogue, AI chats and card trading |

Full 56-day reference season earnings: up to 8,400 MOHAE from daily sources, 2,400 weekly, 600 dummy events = 11,400 plus 10 pass tickets. Without all activities these numbers are not guaranteed. Season pass requires 5,000 season XP. Every economic mutation is atomic and carries a unique operation receipt.

Before production: complete a live three-token test guild smoke test, Docker boot/restore, offsite encrypted backup, owner-reviewed privacy and moderation policy, role permission audit and production-grade schema migration plan.
